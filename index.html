Misión

Qué es AquaLogic y cómo obtiene los datos.

AquaLogic es un simulador matemático que sirve para calcular y monitorear el agua de cualquier tipo de cisterna o almacenamiento.

Está enfocado a instituciones académicas, pero puede utilizarse en todo tipo de situaciones (por ejemplo, una familia).

Esta herramienta de supervisión inteligente predice el agotamiento, detecta fugas invisibles y recomienda ajustes de consumo según la matrícula.

Sensores

Cómo se miden los litros que consume la escuela.

En cada cisterna

AquaLogic implementa en su sistema de cálculo un sensor en cada cisterna. El sensor calcula cuántos litros se consumieron durante el día. Para regular las cantidades máximas de cada área sería necesario instalar tuberías para diferentes propósitos y un medidor independiente para cada una, según el área.

Escuelas de bajos recursos

Para escuelas de bajos recursos se haría el cálculo con el promedio de litros que consume cada persona, sin necesidad de medidores o sensores independientes.

Análisis matemático

Datos, reserva mínima, tiempo hasta la reserva, detección de fuga y gráficas, paso a paso.

Datos

Alumnos totales: N = 400

Volumen inicial: V₀ = 50,000 L (cisterna llena)

Consumo diario: D = N · C = 400 × 25 = 10,000 L/día

Porcentajes: deben cumplir el 100 %, ejemplo: 35 + 5 + 20 + 10 + 30 = 100

Reserva mínima (30 %)

Función diaria por alumno: R(C) = 0.30 · C → R(C) = 0.30 · 25 = 7.5 L

Función semanal por total de cisterna: R(C) = 0.30 · C → R(C) = 0.30 · 50,000 = 15,000 L

Cada litro más de capacidad agrega 0.30 L de reserva: L(R) = L · R

Tiempo hasta la reserva

Función: V(t) = 50,000 − 10,000t

Se iguala a la reserva: 50,000 − 10,000t = 15,000

Se despeja: t = 35,000 / 10,000 = 3.5 días hasta llegar a la reserva

En caso de fuga

Si el sistema detecta una fuga de 2 L por minuto:

Lecturas del sensor: V₁ = 50,000 L y V₂ = 49,880 L (con 60 min entre lecturas)

V′ ≈ (V₂ − V₁) / Δt = (−120) / 60 = −2 L/min

Si la escuela no está en uso y V′ < −0.5 L/min, hay alerta.

Como 2 > 0.5, se activa la alerta de fuga.
